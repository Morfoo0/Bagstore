# Paleta aprobada: Beige clásico

| Color | Código | Uso previsto |
| --- | --- | --- |
| Marfil | #FAF7F0 | Fondo principal |
| Arena | #E8DCC8 | Secciones y superficies secundarias |
| Beige cálido | #CDB89E | Acentos y bordes decorativos |
| Café profundo | #493A30 | Texto principal y botones |

Paleta elegida por el usuario para la tienda de bolsas escolar.
Usar texto café profundo sobre los fondos claros; para botones café, usar texto marfil.
Verificar contraste de estados, controles y textos al implementar las pantallas. No utilizar beige cálido como texto pequeño sobre marfil.
El nombre comercial de la tienda sigue pendiente de confirmación; Bagstore es el nombre actual del repositorio.
